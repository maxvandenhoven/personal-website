Projects

These projects explore game-playing AI, agent evaluation, and web development through hands-on experiments.

    skill-evals

    A framework for evaluating agent skills across models and coding agents. By comparing isolated runs with and without a skill, it helps check whether the agent selects the instructions, follows the workflow, and produces a better result.

    hive

    Hive is a two-player game in which insect tiles are used to surround the opponent's queen. This project brings together a rules engine, search-based agents, and a web app for playing against them, with tests and timed matches to check correctness and compare how the agents play.

    imposter

    In Imposter, most players know a secret word while one has to bluff through the clues. Having LLM agents play the game offers a way to explore how models behave, alongside the orchestration and tracing needed to keep a full game running reliably.
